# aurora

<img src="https://cdn.hackclub.com/01a0b1f5-589a-74d1-ba98-8b34c7b2bc76/aurora.png" width="800" alt="aurora, seed 6">

a shader for [wpr](https://github.com/maxwofford/wpr), the wallpaper manager.

```sh
brew tap maxwofford/wpr && brew install wpr   # if you don't have wpr yet
wpr install maxwofford/aurora
wpr gen aurora                                # a new one, set as your wallpaper
wpr enable aurora                             # add it to your rotation
```
